## 關鍵判定摘要

### 1.2-aqp4-polarization-endfeet → verified / tier A
- Iliff 2012 直接證明 AQP4 在星狀膠細胞終足的極化分佈
- 此概念在後續多項研究中驗證（含人類 post-mortem）
- tier A（雖然是 rodent 原始發現，但是 foundational + 多重驗證）

### 1.2-aqp4-ko-csf-influx-60pct → partial / tier C
- **數值 mismatch**：原文寫「高達60%」，Iliff 2012 abstract 報告的是「~70% reduction in interstitial solute clearance」(不是 CSF influx)
- 60% 可能來自其他 Aqp4 KO 研究的同類測量，但 backfill 階段沒找到明確出處
- 判定 partial：方向支持（KO 確實降低）、數值對位不精確
- tier C（rodent in vivo two-photon）

### 1.3-sleep-interstitial-volume-60pct → verified / tier C
- **完美對位**：Xie 2013 Science abstract 原文：「sleep or anesthesia are associated with a **60% increase** in the interstitial space」
- 數值與原文一致
- tier C（rodent in vivo two-photon）

### 1.3-wake-csf-influx-reduction-95pct → unverified
- **找不到 95% 確切出處**：Xie 2013 abstract 沒提到 95%
- 95% 數字可能是 LLM 誇大或來自其他實驗
- status=unverified，後續需要更深的文獻搜尋

### 1.3-norepinephrine-suppression → verified / tier C
- Hauglund 2025 Cell 直接證明 NE、vasomotion、CSF 振盪在 NREM 期間同步
- 「locus coeruleus → NE → 細胞體積 → ISF 壓縮」鏈條被實驗支持

### 1.3-vasomotion-driver → verified / tier C
- Hauglund 2025 Cell：NE-mediated slow vasomotion 驅動 glymphatic clearance
- 與原 claim 「血管直徑的低頻自發性振盪」完全對位

## 與 glycocalyx 對比

glycocalyx 的 backfill 經常遇到「數值對位錯」（同一研究多個百分比）— glymphatic 也有同樣問題（1.2-aqp4-ko-csf-influx-60pct 的 60% vs Iliff 2012 的 70%）。

但 glymphatic 額外的問題是**「根本性出處錯誤」**：原文把 review 當成原創論文引用，backfill 階段需要主動找出真正的原始文獻並標記。
